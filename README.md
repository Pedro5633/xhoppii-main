# Xhoppii - Trabalho de HTML/CSS

Projeto desenvolvido para a disciplina de Eletiva Linguagem de Programação IV INTERNET.

## Estrutura do Projeto
- `Index.html`: Página inicial
- `view/`: Páginas internas do sistema
- `assets/`: Arquivos de estilo, imagens e scripts

## Como visualizar
Abra o arquivo `Index.html` em qualquer navegador.
